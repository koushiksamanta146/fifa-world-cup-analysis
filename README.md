# fifa-world-cup-analysis
FIFA World Cup performance analysis using SQL and Excel to uncover team, scoring, and tournament insights.

 FIFA World Cup Performance Analysis
 
Project Overview

This project analyzes FIFA World Cup match-level data to uncover meaningful insights into team performance, goal-scoring patterns, defensive strength, group competitiveness, and match outcomes.

The analysis was performed using MySQL and Excel, transforming raw match data into structured insights and visual presentations.

Project Objectives

The key objective of this project is to answer important analytical questions such as:

Which teams scored the most goals throughout the tournament?
Which teams had the strongest defensive performance?
How did team order impact match outcomes?
Which teams performed best in penalty shootouts?
Which groups were the most competitive?
Which groups produced the highest number of goals?
What patterns can be identified from team and match performance?
Tools & Technologies
MySQL – Data cleaning, transformation and SQL analysis
Microsoft Excel – Data analysis, visualization and presentation
SQL – Aggregation, CTEs, window functions and analytical queries

 Key Analysis
1. Top Scoring Teams

Identified the teams with the highest cumulative goals and analyzed their average goal difference per match.

2. Clean Sheet Leaders

Compared teams based on their clean-sheet performance to identify the strongest defensive teams.

3. Team Order Impact

Analyzed whether being listed first or second in a match had an impact on win rate and points earned.

4. Penalty Shootout Performance

Analyzed matches decided by penalty shootouts and evaluated penalty-scoring performance.

5. Group Competitiveness

Compared teams within each group to identify the groups with the tightest goal-difference spread.

6. Group Goal Production

Analyzed cumulative goals scored by each group to identify the highest-scoring group.
